# PortfolioS6
Site web qui présente mes projets avec les compétences associées pour la matière Portfolio du dernier semestre de mon BUT informatique

Ce site web personnel présente:
- **Présentation personnelle**: Une page d'accueil complète avec photo de profil
- **Compétences professionnelles**: Les 6 compétences du programme national détaillées (Réaliser, Optimiser, Administrer, Gérer, Conduire, Collaborer)
- **Projets réalisés**: Une vitrine des projets qui illustrent l'acquisition des compétences
- **Langages et technologies**: Showcase des technologies maîtrisées
- **Curriculum Vitae**: Téléchargement des différentes versions de CV
- **Formulaire de contact**: Pour les opportunités professionnelles

**Année académique**: 2025-2026
**Formation**: BUT Informatique - Semestres 5-6
